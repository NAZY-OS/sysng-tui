# sysng-tui

**A simple GNU - Libre System monitor terminal-ui**


## Quick Start

1. Clone the repository:
   ```sh
   git clone https://github.com/NAZY-OS/sysng-tui.git
   cd sysng-tui
   ```

2. Change Permission

   ```sh
   chmod +x build.sh
   ```

3. Run Script
   ```sh
   ./build.sh
   ```
